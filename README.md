IoT-Based Hand Gesture Recognition System for Robot Navigation and Control

Project Overview

This project uses hand gestures to control robot navigation through an IoT-based system.

Source Code

- "transmitter.ino" – Transmitter-side Arduino code.
- "receiver.ino" – Receiver-side Arduino code.

Technologies Used

- Arduino
- Embedded Systems
- IoT
- Hand Gesture Recognition

Project Objective

To develop a gesture-based robot control system that enables navigation using hand movements.
